# Requirements: deployment

## Introduction
Deploy the backend to Render (Docker + managed PostgreSQL) and the frontend to Netlify or Vercel, with all configuration in environment variables.

### R1 Backend image
1. `backend/Dockerfile` SHALL build the jar in a Maven + JDK 21 stage and run it on a JRE 21 image as a non-root user.
2. The container SHALL listen on `$PORT`.
3. WHEN `DATABASE_URL` is in `postgres://user:pass@host:port/db` form (Render) THEN the app SHALL convert it to a JDBC URL and credentials automatically.

### R2 Render
1. `render.yaml` SHALL define a free PostgreSQL database and a Docker web service with health check `/api/health`.
2. `JWT_SECRET` SHALL be generated by Render; `CORS_ALLOWED_ORIGINS` and `CLOUDINARY_URL` SHALL be set in the dashboard.

### R3 Frontend hosting
1. `npm run build:prod` SHALL write `environment.prod.ts` from the `API_URL` env var and build to `dist/frontend/browser`.
2. `netlify.toml` and `vercel.json` SHALL configure the build and an SPA fallback to `index.html`.

### R4 CORS and secrets
1. The API SHALL only accept cross-origin calls from origins listed in `CORS_ALLOWED_ORIGINS` (comma-separated).
2. No secret SHALL be committed; `.env.example` documents every variable.
